Where the data comes from

Synthetic · reproducible
Origin
Generated by a script in this repository. No real patient records are involved, and none were available — which is the normal constraint when demonstrating this work outside a client engagement.
Modelled on
A donor screening laboratory. The assay panel is the marker set mandated for allogeneic blood donation screening under EU Directive 2002/98/EC — NAT and serology for HIV, HBV and HCV, plus syphilis and anti-HBc — carrying real LOINC codes.
Shape
What a fifteen-year-old system actually hands over: pipe-delimited flat files, Latin-1 encoded, local wall-clock timestamps with no offset column, numeric results held as free text, and a control-total manifest.
Reproducible
Deterministic from a seed. The same seed reproduces the same 15,839 rows and the same SHA-256 checksums, so the dataset the evidence was produced from can be regenerated exactly.
Known answer
The injected defects are logged to an oracle file that the migration code never reads. Detection is attributed afterwards, from which control fired — so the migration cannot be tuned to the answer.

Why one defect is worth showing

DEF-04
D000001 46 65 72 72 e1 6e 64 65 7a clean Latin-1
D000028 56 c3 ad 6c 63 68 65 7a double-encoded

Byte e1 is not valid UTF-8, so the clean row displays as Ferr�ndez and looks broken. The pair c3 ad is valid UTF-8, so the corrupt row displays as Vílchez and looks perfect.

The corruption is invisible to the eye and provable at the byte level. Six donors in five hundred. This is why migration verification is done on bytes and counts rather than by looking at a sample.

What was produced

Executed against live AWS
Specification
Source-to-target mapping of 43 fields, 14 rated critical, consumed directly by the transform and by the traceability matrix — so the specification and the code cannot silently disagree.
Traceability
13 requirements, 12 controls, all VERIFIED. The matrix is generated from runs that happened, not typed. Its first generation reported three requirements whose controls nothing exercised; those gaps were closed rather than edited out.
Evidence
24,773 audit entries, each carrying the rule applied, the requirement it serves and the original value. 17 requirement-tagged tests. Installation qualification run against real AWS: 23/23 on credential scope, 32/33 on configuration.
Open deviation
One check fails and is left failing: the alerting topic has no confirmed subscriber. A pack that reports only what passed is describing a rehearsal.
